# BUG-02. На английской главной клик по логотипу возвращает на русскую версию сайта

| Поле | Значение |
|---|---|
| **ID** | BUG-02 |
| **Компонент** | Шапка сайта → логотип-заголовок, страница `index-eng.html` |
| **Приоритет** | Medium |
| **Серьёзность** | Major |
| **Тип** | Функциональный дефект (навигация / локализация) |
| **Окружение** | Windows 10 Pro 22H2, Chromium, viewport 1280×720, `http://127.0.0.1:8777/index-eng.html` |
| **Найдено** | 17.08.2026 |
| **Связанный тест-кейс** | TC-04 |

## Описание

Логотип в шапке — стандартная ссылка «домой». На английской главной странице он ведёт
на русскую главную `index.html`, а не на `index-eng.html`. Англоязычный посетитель,
кликнув по логотипу, внезапно оказывается на русской версии сайта и должен вручную
переключать язык флагом.

Дефект изолированный: на всех остальных английских страницах
(`chaika1-eng.html`, `chaika2-eng.html`, `chaika3-eng.html`, `contacts-eng.html`)
логотип корректно ведёт на `index-eng.html`.

## Шаги воспроизведения

1. Открыть `http://127.0.0.1:8777/index-eng.html`.
2. Убедиться, что страница английская (заголовок вкладки `Cottages "Chaika"`, меню Main/Chaika-1/…).
3. Кликнуть по заголовку-логотипу **Cottages "Chaika" Kazan** в шапке.

## Фактический результат

Открывается русская главная страница:

```js
// до клика
location.pathname  // "/index-eng.html", document.title === 'Cottages "Chaika"'
// после клика
location.pathname  // "/index.html"
document.title     // 'Коттеджи "Чайка"'
[...document.querySelectorAll('.menu a')].map(a => a.textContent.trim())
// → ["Главная", "Чайка-1", "Чайка-2", "Чайка-3", "Контакты"]
```

## Ожидаемый результат

Страница остаётся английской: открывается `index-eng.html` (или ссылка ведёт на текущую
страницу без перезагрузки), язык интерфейса не меняется.

## Причина (анализ кода)

`index-eng.html:20` — в ссылке логотипа не заменён путь при копировании шаблона с русской страницы:

```html
<h1><a href="index.html">Cottages "Chaika" Kazan</a></h1>
```

Для сравнения, `contacts-eng.html:20` содержит корректный вариант:

```html
<h1><a href="index-eng.html">Cottages "Chaika" Kazan</a></h1>
```

## Предлагаемое исправление

В `index-eng.html:20` заменить `href="index.html"` на `href="index-eng.html"`.

## Воспроизводимость

100 %. Затронута одна страница из десяти.
