## Известные проблемы

- `gh` CLI недоступен ни в Bash, ни в PowerShell — `gh pr create` выполнить
  нельзя без установки нового инструмента. По решению пользователя PR не
  создавался: изменения коммитятся и пушатся прямо в `main`.
- Node.js в окружении отсутствует — придётся ставить перед автотестом,
  установка ещё не проверена на этой машине.
- `sessions/session-1.md`: не заполнена таблица инструментов, не обновлено
  поле «Статус».
- `sessions/session-2.md`: заголовок скопирован с ошибкой («Сессия 1» вместо
  «Сессия 2»), сам файл пока пуст.
- Разделение сессий (написание кода тестируемого сайта vs. его тестирование)
  для этой задачи не совсем применимо буквально: сайт `fmarsm.github.io-main`
  — уже существующий чужой/личный проект, не написанный агентом в рамках
  этого домашнего задания, поэтому «наивная» и «спека»-сессии в этом
  задании имеют смысл только для самого процесса тестирования, а не для
  разработки сайта — это допущение зафиксировано в `SPEC.md`.
