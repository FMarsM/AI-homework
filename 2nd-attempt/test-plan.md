# Тест-план — «Чайка» (2-я попытка)

- **Дата:** 2026-08-16
- **Объект:** `fmarsm.github.io-main` (10 HTML-страниц RU/ENG), поднят локально
  через `python -m http.server 8080 --directory fmarsm.github.io-main`.
- **Инструмент:** встроенный Browser MCP (Chromium), Playwright для автотеста.
- **Ширины для адаптива:** 375 / 768 / 1024 / 1440 px.

Список составлен **до** прогона, по мотивам сценариев из `SPEC.md`. Пункты
2, 5, 8, 9, 11, 12 (и часть 4) — негативные/граничные, что больше трети от 10.

| № | Проверка | Тип | Ожидаемый результат |
|---|----------|-----|----------------------|
| 1 | Открыть `index.html` на 1440 px — сайт загружается, слайдер, меню, карта видны | Позитив | Страница отображается без визуальных провалов |
| 2 | Загрузка статических ресурсов (картинки/CSS/шрифты) на всех 10 HTML-страницах — консоль/network без 404 | **Негатив** | Нет ошибок 404; известное подозрение — пути через `\` вместо `/` |
| 3 | Прямой заход на `chaika2.html`, минуя `index.html` | Позитив | Страница открывается, меню и переключатель языка работают |
| 4 | Переключение языка RU↔ENG с внутренней страницы (например `chaika1.html` → `chaika1-eng.html`) | Позитив | Остаёмся на эквивалентном разделе, а не сбрасываемся на главную |
| 5 | Обход всех пунктов верхнего меню на 1440 px | Позитив | Каждый пункт ведёт на свою страницу без 404 |
| 6 | Мобильное меню на 375 px: открыть кнопкой, кликнуть мимо | **Негатив/граничный** | Меню открывается и закрывается корректно |
| 7 | Слайдер на главной: пролистать до последней карточки и обратно (точки/стрелки) | Позитив | Слайдер переключается без залипания на границах |
| 8 | Форма бронирования: отправка с пустыми обязательными полями | **Негатив** | Отправка блокируется, показывается стандартная HTML5-валидация |
| 9 | Поле «Количество заселяющихся»: ввод `-5`, `0`, `999`, `abc` | **Негатив/граничный** | Значение либо отклоняется, либо приводится к допустимому диапазону согласно `handleChange()` |
| 10 | Полностью корректное тестовое заполнение формы и отправка (`ФИО: TEST QA 2026-08-16`) | Позитив | Форма отправляется, показывается `#success`, сообщение исчезает через ~3 сек |
| 11 | Обход интерактивных элементов страницы клавиатурой (Tab) на `contacts.html` | **Негатив/граничный** | Фокус визуально виден на всех полях/кнопках, порядок логичен |
| 12 | Обход ссылок в футере/логотипе на каждой языковой версии | **Негатив/граничный** | Ни одна ссылка не ведёт на несуществующую страницу (404) |

## Допущения на этот прогон

- Тестовые отправки формы помечаются `TEST QA <дата>` в поле ФИО, не более 10 за всю работу над задачей.
- Автотест Playwright пишется под один из найденных дефектов (не smoke-тест).
- Правки кода сайта в рамках этой попытки не делаются — только фиксация багов.
