# Тест-план — сайт «Коттеджи "Чайка"» (`fmarsm.github.io-main`)

- **Дата составления:** 2026-08-16
- **Составлен:** до начала прогона
- **Объект:** статический сайт, 10 HTML-страниц (5 RU + 5 ENG), без бэкенда;
  форма бронирования отправляется на внешний Google Apps Script.
- **Стенд:** `python -m http.server` на `http://localhost:8080`, каталог
  `fmarsm.github.io-main`.
- **Браузер:** Chromium (встроенный Browser MCP + Playwright).
- **Ширины экрана:** 375 / 768 / 1024 / 1440 px.

## Границы тестирования

- Код сайта не правится — только чтение и запуск.
- **Форма бронирования боевая.** Реальные отправки на продовый Google-эндпоинт
  не выполняются вообще. Поведение при отправке проверяется с перехватом
  (блокировкой) сетевого запроса к `script.google.com`, чтобы ни одна заявка
  не ушла владельцу сайта. Это же даёт проверку поведения при сбое сети.
- Кросс-браузерность (Firefox/Safari) — вне объёма, прогон только в Chromium.
- Бэкенд Apps Script (что он записывает в таблицу) — вне объёма, недоступен.

## Проверки

| № | Что проверяем | Как | Ожидаемый результат |
|---|---|---|---|
| 1 | Доступность всех 10 страниц | Запрос каждой страницы по HTTP | 200 OK, страница отрисована, `<title>` непустой |
| 2 | Отсутствие битых ресурсов | Загрузка каждой страницы с логом network | Нет ответов 4xx/5xx по CSS, изображениям, шрифтам |
| 3 | Навигация по меню, RU | Клик по каждому из 5 пунктов на `index.html` | Переход на соответствующую RU-страницу, 200 OK |
| 4 | Навигация по меню, ENG | Клик по каждому из 5 пунктов на `index-eng.html` | Переход на соответствующую ENG-страницу, 200 OK |
| 5 | Переключение языка | На каждой из 5 RU-страниц нажать флаг ENG, затем флаг RU | Остаёмся на той же смысловой странице, язык меняется, содержимое переведено |
| 6 | Ссылка «Контакты» в подвале | Клик по ссылке в подвале на всех 10 страницах | Переход на `contacts.html` / `contacts-eng.html` |
| 7 | Бургер-меню на узких ширинах | 375 / 768 / 1024: клик по кнопке-бургеру, затем по пункту меню | Меню раскрывается, пункт кликабелен, происходит переход |
| 8 | Горизонтальное меню на 1440 | Ширина 1440, осмотр шапки | Меню видно всегда, кнопка-бургер скрыта |
| 9 | Слайдер фотографий | `index.html` и `chaika1.html`: переключение точками и стрелками | Кадр меняется, соответствует выбранному индексу |
| 10 | Обязательные поля формы | `contacts.html`: submit с пустыми полями | Браузерная валидация не пускает, заявка не уходит |
| 11 | Поле «Количество заселяющихся» | Ввести `abc`, затем `999`, затем `-5` | Нечисловое значение отклоняется; значение приводится к диапазону 0…30 |
| 12 | Даты заезда/отъезда | Дата отъезда раньше даты заезда | Форма не принимает такой интервал, показана ошибка |
| 13 | Поведение при сбое отправки | Submit при заблокированном запросе к `script.google.com` | Пользователю показана ошибка, а **не** сообщение об успехе |
| 14 | Отзывчивость вёрстки | 375 / 768 / 1024 / 1440 на всех типах страниц | Нет горизонтального скролла, контент не обрезан, скриншот на каждой ширине |

## Критерии

- **Проверка провалена**, если фактический результат расходится с ожидаемым
  и расхождение подтверждено скриншотом, фрагментом разметки или логом.
- Спорные случаи, где ожидаемое поведение нигде не зафиксировано, выносятся
  в раздел «Неоднозначности» отчёта, а не трактуются на своё усмотрение.
